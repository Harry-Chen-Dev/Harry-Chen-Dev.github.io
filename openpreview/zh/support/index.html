常见问题

支持哪些文件？

Markdown（.md、.markdown）、JSON、纯文本及文本形式的源代码。PDF、Word 和图片等二进制文件不是本应用的文稿编辑格式。使用 ⌘O 或拖入文件打开。

如何切换查看方式？

Markdown 支持“原文”和“预览”；JSON 支持“原文”“格式化”和“结构”。目前应用界面主要为简体中文。

如何分屏和对比？

右键标签选择左右或上下分屏。两个窗格打开不同文件后，点击顶部编辑按钮左侧的对比图标，再次点击结束对比。左侧或上方为参考，右侧或下方为当前。

搜索按钮在哪里？

使用 ⌘F 查找当前文件，⌃⌘F 搜索已打开文件；⌘G 跳到下一个结果，⇧⌘G 跳到上一个。结构或对比视图中查找可能切回原文。

什么时候会保存？

默认只读；⌘E 进入编辑，⌘S 保存，⇧⌘S 另存为。不会自动把草稿写入磁盘。关闭有改动的文稿时可选择保存、不保存或取消；未保存草稿不具备自动备份或崩溃恢复保证。

其他程序也修改了文件怎么办？

存在草稿时，应用会在覆盖已变化的文件前提示冲突。可保留草稿并另存为，或核对磁盘版本。请自行保留重要文件的备份。

为何预览或对比不可用？

单文件读取上限 32 MiB。内容超过 1,000,000 个 UTF-8 字节时进入简化文本模式。精细对比的两个文件合计限制 30,000 行及 2,000,000 个 UTF-8 字节；JSON 嵌套最多 64 层。对比还要求分屏中打开两个不同文件。

Markdown 图片如何查看？

点击图片占位链接。本地图片需要授权其文件夹；远程图片会先询问当前文稿的加载许可，允许后才请求图片服务器。图片在独立窗口预览。远程请求超时为 20 秒，下载上限为 10 MB；并非所有相对资源和 Markdown 扩展都受支持。

是否需要订阅？

不需要。计划采用 Mac App Store 一次性付费下载，无内购。目前尚未发布，价格和可用地区以上架后的商店信息为准。

如何清除本地记录？

使用完毕后关闭文稿，先保存需要保留的内容。macOS 可能保留最近文件、窗口设置和系统网络缓存。仅删除 .app 不保证清除这些记录，原文件也不会随应用删除。需要清理应用相关记录时可联系支持。
