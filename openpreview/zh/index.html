阅读、查看、比较。

在 Mac 上，为 Markdown、JSON 和文本留一处安静的空间。

把文稿放在一起

OpenPreview 用顶部标签整理打开的文件。阅读 Markdown 的标题、列表、表格与代码块，需要时随时切回原文。

看清数据结构

在 JSON 原文、格式化文本和可展开的结构树之间切换。查看格式化结果不会覆盖原文件。

并排看见变化

右键点击标签，选择左右或上下分屏。两个窗格打开不同文件后，通过顶部对比按钮查看文本增删差异。左侧或上方为参考文件。

修改由你决定

文稿默认只读。使用 ⌘E 进入编辑，⌘S 显式保存；⌘F 查找当前文件，⌃⌘F 搜索已打开的文件。

本机处理，按需连接

文稿解析、搜索和比较在本机完成，无需账号。远程图片只在主动操作并允许后加载；外部链接由浏览器或邮件应用打开。

获取应用

即将登陆 Mac App Store。采用一次性付费下载，无订阅、无应用内购买。价格以上架后的商店页面为准。

系统 · macOS 26 或更高版本
界面 · 目前主要为简体中文
文件 · 读取上限 32 MiB；超过约 1 MB 使用简化文本模式

对比为文本差异，不是语义分析或 Git 合并。图片处理与其他限制详见支持页面。
