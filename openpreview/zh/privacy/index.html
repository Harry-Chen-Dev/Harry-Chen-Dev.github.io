OpenPreview 隐私政策

文稿在你的 Mac 上处理；按需发生的外部连接在下文说明。

生效日期 · 2026 年 9 月 10 日
适用范围 · OpenPreview Mac 版 0.1.0
开发者及联系方式 · Harry Chen · harrychendev@gmail.com

文稿与本地处理

OpenPreview 通过 macOS 文件权限读取你选择的文件。Markdown 解析、JSON 查看、搜索和文本对比都在本机进行。应用没有开发者运营的文稿上传服务、账号系统、广告、分析 SDK 或自建崩溃上报服务。

原文和未保存草稿保留在运行中的应用内；保存或另存为写入你选择的目标文件。阅读和对比不会自动保存修改。执行复制或粘贴命令时，应用会使用系统剪贴板。

本地记录与存储

macOS 可能保留最近文稿引用（包括路径）和窗口位置。系统网络会话可能保存已请求资源的缓存和 Cookie。OpenPreview 不提供云同步或自动草稿备份服务。位于云同步文件夹内的文件，以及设备备份，受你所选服务及系统设置管理。

按需图片与外部链接

本地 Markdown 图片需要你授权其所在文件夹。仅打开文稿不会自动请求远程图片；必须主动点击图片并允许当前文稿加载。许可用于当前打开的文稿，关闭文稿即可结束后续加载使用的这项许可。

允许加载后，请求会访问图片地址及其查询参数或重定向目标。目标服务器会接收到 IP 地址和常规网络请求信息，也可能按照自己的政策保留日志或使用 Cookie。应用使用系统 URLSession 共享会话，不经过开发者代理服务器。请避免加载不可信地址。

网页、邮件、支持及隐私链接由对应的系统应用打开；这些应用和目标服务遵循各自的隐私规则。关闭文稿不能撤回已经发出的请求。

支持邮件

如果你发送支持邮件，Harry Chen 会通过邮件服务收到邮箱地址、正文，以及你主动提供的姓名或附件。这些信息用于答复问题和排查故障，不用于广告。请仅提供必要信息并先脱敏。

支持往来在处理请求和相关跟进所需期间保留，不再需要时删除，适用的法定义务除外。你可以通过下方邮箱请求访问、更正或删除相关信息。

本网站与其他服务

本网站由 GitHub Pages 托管，使用 Google Fonts。访问页面可能向这些服务发送 IP 地址和常规请求信息。页面不添加分析或广告脚本。基础设施的数据处理分别受 GitHub 隐私声明和 Google 隐私政策约束。

Mac App Store 的购买、下载及通过 Apple 分享的诊断信息，受 Apple 隐私政策和你的设置管理。OpenPreview 不索取或保存银行卡信息。本地 Markdown 解析使用开源 swift-markdown 和 swift-cmark 库，它们不是分析服务。

你的选择与删除

你可以拒绝远程图片请求、不点击外部链接，并关闭文稿以停止应用后续使用其访问权限。退出前请保存或放弃草稿。移除 OpenPreview 不会删除你的原文件；仅移除应用包也可能留下系统偏好、最近文件记录或网络缓存，需要清理时请联系支持。清理本地记录不能删除外部图片服务器或邮件服务已保留的日志。

政策变更与联系

应用行为变化时，我们会更新此政策和生效日期。隐私问题或相关请求请发送至：harrychendev@gmail.com。
